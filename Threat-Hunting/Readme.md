Wazuh Lab 02 - Threat Hunting Basics

---
Overview

This lab focused on exploring the Threat Hunting module in Wazuh and understanding how security events are collected, analyzed, and displayed from a monitored Windows 11 endpoint.

The objective was to learn how to navigate security events, identify event severity levels, review rule details, and investigate Windows authentication activity through the Wazuh SIEM platform.

---
Objectives
Access the Threat Hunting module.
Review security events generated by the monitored endpoint.
Understand Wazuh event structure.
Analyze event details and associated rules.
Investigate Windows authentication events.
Learn how Wazuh categorizes and prioritizes alerts.

---
Environment

Wazuh Version: 4.14.7

Endpoint Name: Gab

Operating System: Microsoft Windows 11 Pro

Agent ID: 001

---
Threat Hunting Module Overview

The Threat Hunting module provides centralized visibility into security events collected from monitored endpoints.

Key components reviewed during this lab:

Events

Displays all collected logs and alerts generated by the endpoint.

Rule ID

Unique identifier assigned to the detection rule that generated the event.

Rule Level

Severity rating assigned to an event.

Severity ranges:

0-3   Informational
4-6   Low
7-9   Medium
10-12 High
13-15 Critical

---
Event Details

Provides detailed information including:

Agent name
Rule information
Decoder
Timestamp
Full log data

Conclusion

The Threat Hunting module provided centralized access to events generated by the monitored Windows endpoint. The lab demonstrated how Wazuh collects, organizes, and displays security events while allowing analysts to review authentication activity and investigate endpoint events. The exercise established a foundation for future monitoring activities such as File Integrity Monitoring, Authentication Monitoring, MITRE ATT&CK analysis, and Incident Investigation.
