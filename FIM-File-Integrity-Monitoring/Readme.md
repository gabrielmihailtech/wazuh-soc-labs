Wazuh Lab 04 - File Integrity Monitoring (FIM)

---
Overview

This lab focused on understanding and analyzing the File Integrity Monitoring (FIM) capabilities of Wazuh.
The objective was to identify monitored files and Windows Registry locations, review integrity monitoring events, and investigate changes detected by the Wazuh agent on a Windows 11 endpoint.

---
Objectives
Explore the File Integrity Monitoring module.
Review monitored files and Windows Registry entries.
Analyze registry modification events.
Identify file and registry change alerts generated by Wazuh.
Understand the security relevance of integrity monitoring.

---
Environment

Platform: Wazuh Cloud

Agent Name: Gab

Agent ID: 001

Operating System: Microsoft Windows 11 Pro

Wazuh Version: 4.14.7

---
Inventory Review

The File Integrity Monitoring inventory revealed that Wazuh was monitoring both critical Windows system files and Windows Registry objects.

Windows Registry (9,575 entries)

Analysis

Wazuh detected the creation of a new Windows Registry key within the TPM (Trusted Platform Module) registry structure.

The alert demonstrated that Wazuh was actively monitoring registry modifications and generating integrity monitoring events when new keys were created.

---
Security Impact

File Integrity Monitoring is an important defensive capability because attackers often modify files and registry locations to:

Establish persistence
Change security settings
Disable defenses
Modify application behavior
Maintain access after system reboots
Hide malicious activity

Wazuh helps security analysts detect these changes by generating alerts whenever monitored files or registry objects are modified.

---
Key Findings
Wazuh successfully monitored critical Windows files.
Wazuh actively monitored Windows Registry entries.
Registry additions and deletions generated security events.
Each event contained useful investigation details including timestamps, paths, event types, rule IDs, and severity levels.
File Integrity Monitoring provided visibility into system changes that could be relevant during incident investigations.

---
Conclusion

This lab demonstrated the File Integrity Monitoring capabilities of Wazuh on a Windows 11 endpoint.
The platform successfully detected Windows Registry changes and provided detailed event information for investigation.
File Integrity Monitoring is a valuable security control that helps analysts identify unauthorized system modifications and investigate potential persistence mechanisms used by attackers.
